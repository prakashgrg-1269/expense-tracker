# 💰 Expense Tracker

A Python CLI expense tracker app with full CRUD functionality and JSON storage.

## What it does
- 📋 Display all expenses in a clean list
- ➕ Add new expenses
- ✏️ Update existing expense status
- ❌ Delete expenses
- 💾 Saves all data to a JSON file so nothing is lost when you close the app

## Technologies Used
- Python
- JSON (data storage)
- Modular Programming (separate files for each feature)

## How to Run
```bash
python main.py
```

## Project Structure
```
expense-tracker/
├── main.py        # Main menu and program entry point
├── add.py         # Add expense logic
├── display.py     # Display expenses logic
├── update.py      # Update expense logic
├── delete.py      # Delete expense logic
└── expenses.json  # Data storage file
```
